# 강의 분석 (lecture-analysis)

파이프라인 본체는 **스킬 폴더**(이 파일이 있는 곳, 아래에서 `<스킬 폴더>`)의 `analyze.sh`(스테이지 s10~s80)다. **스킬은 얇은 오케스트레이터 — 분석·판정 로직을 대화에서 재수행하지 말고 스크립트를 실행하라.** LLM 스테이지는 스크립트 내부에서 `claude -p`로 돈다(대화 세션이 의미 판별을 대신하지 않는다 — 재현성). 교시별 LLM 호출(s30·s40)은 스크립트가 **병렬 sub-agent**(독립 `claude -p` 프로세스, 기본 3개 동시 — `LA_PARALLEL`)로 돌린다 — 대화의 Agent 툴로 교시를 나눠 맡기지 말 것(같은 일을 재현성 없이 두 번 하는 셈이다). **Workflow 팬아웃도 마찬가지다** — 세션에 Workflow 도구가 보여도 쓰지 않는다: 툴 없는 `claude -p`에 마스킹된 payload만 넣는 현재 경계(재현성·mask_names)를 파일 접근 가능한 에이전트가 깨고, 교시 수는 manifest에 고정돼 팬아웃으로 얻는 게 없다.

## 절차

1. 데이터 폴더 받기: 사용자가 폴더를 드래그하거나 경로를 말한다. 폴더에 녹취록 txt·
   녹음 파일이 없으면 "이 폴더에 녹취 파일이 보이지 않는다"고 되묻는다(엉뚱한 폴더가
   가장 흔한 실수). 파일이 흩어져 있으면 한 폴더로 모으는 것을 제안한다.
2. 강의명 확인 후 `bash <스킬 폴더>/analyze.sh init <데이터 폴더> --name <강의명>` —
   `./LECTURE_ANALYSIS/{강의명}_{시각}/manifest.toml`이 생긴다. 강의 날짜(`date`)를
   실제 강의일로 고치게 한다(산출물 파일명에 들어간다).
   **실행 위치는 사용자의 작업 폴더(대화의 cwd)다** — 산출물은 실행한 자리의
   `LECTURE_ANALYSIS/`에 쌓인다. 스킬 설치 폴더로 `cd` 하지 않는다(하면 사용자 손이
   닿지 않는 설치 폴더 안에 남의 강의 녹취 분석이 쌓인다). 스크립트는 항상 절대 경로로 부른다.
3. 교시 매핑(오디오↔txt)을 표로 보여주고 확인받는다 — 어긋나면 말속도·침묵이 통째로
   다른 교시에 붙는다.
4. **mask_names 게이트(건너뛰기 금지)**: "녹취에 등장하는 실명을 알려 주세요(없으면
   '없음')." 전사 텍스트가 Anthropic(국외)으로 나가므로 빈 값 진행은 사용자가 '없음'을
   명시한 경우뿐이다. `plan`을 달았다면 그 문서의 실명도 같은 목록에 넣는다.
5. 실행: `bash <스킬 폴더>/analyze.sh run <manifest>` — 오디오가 있으면 교시당 수 분~수십 분 소요를
   미리 안내(백그라운드 실행 권장). `.venv`가 없으면 s10을 건너뛰고 정밀 음성 지표 없이
   진행한다(원하면 `bash <스킬 폴더>/setup.sh`를 안내). `.venv`는 있는데 ffmpeg가 없으면
   s10이 exit 2로 멈춘다 — `brew install ffmpeg` 후 다시 `run`(setup.sh는 ffmpeg를
   설치하지 않는다).
6. **A층 요약을 그대로 전달** — 원시 빈도·인용 중심. 점수화·등급화·재해석·총평 생성
   금지(리포트가 완성본, 스킬은 낭독자). 공유 파일은
   `outputs/{강의명}_분석리포트_{날짜}.html` 하나다(내부 경로·실행 메타 비노출).
   세션 폴더 README.md가 내비게이션이다.
7. 다음 액션 확정 대화(선택): B7 후보를 보여주고 강사가 고르면 분석데이터 md의 체크박스를
   `- [x]`로 기록하고 `python3 <스킬 폴더>/scripts/s80_html.py <manifest> --force`로
   html 상태 라벨을 갱신한다.
8. 하드 중단 시 종료 코드 표 참조.

## 종료 코드와 대응

`bash <스킬 폴더>/analyze.sh run`은 실패한 스테이지에서 **멈추고** 그 코드를 그대로 내보낸다(어디서 멈췄는지 `중단: sNN (exit N)`으로 표시).

| 코드 | 뜻 | 대응 |
|---|---|---|
| 0 | 정상 종료 | 세션 폴더에 `outputs/{강의명}_분석리포트_{날짜}.html`(공유용) · `outputs/{강의명}_분석데이터_{날짜}.md`(데이터 레이어) · `README.md`(내비게이션) 발행 완료 |
| 2 | 입력 오류 (manifest 부재·TOML 문법·참조 파일 없음·녹취록 형식 변형·오디오 디코딩 실패·**s80 링크/경로 검증 실패**) | 메시지의 파일·필드를 고치고 다시 `run`. s80 검증 실패(깨진 내부 링크·세션·입력·계획(`plan`) 폴더·`$HOME` 경로 노출)는 생성 버그 신호 — 분석데이터 md를 `--force s70`으로 재생성 후 다시 실행 |
| 3 | 하드 중단 — 강사 식별 실패. **원인이 둘이다** | **(a) s20 점유율 60% 미만**: 화자별 발화 샘플이 함께 출력된다 → 샘플을 보여주고 manifest `[speakers] instructor_label`을 수동 지정하게 한다. 지정한 라벨이 **그 교시 파일에 실제로 존재해야** 진행된다(존재하면 저점유율이어도 경고 후 `low_share_override`로 진행, 없으면 오타·교시 착오이므로 다시 중단). **(b) s30 라벨 교차 확인 불일치**(`instructor_check.agrees=false`): 샘플 없이 LLM이 준 사유만 나온다. 점유율 게이트는 이미 통과했으므로 **발화량은 많은데 내용이 강사답지 않은 화자**를 라벨로 삼았다는 뜻이다 — 수동 지정 라벨이 틀렸을 수도 있고, `auto`(최다 발화자)가 실습 주도 수강생·공동 진행자를 집어 온 경우일 수도 있다. LLM이 준 사유를 그대로 보여주고 `instructor_label`을 수동 지정(또는 재지정)하게 한다 |
| 4 | LLM 실패 (s30·s40·s60·s65의 재시도 후 실패) | 스테이지는 실패 교시에 `llm_failed` 기록을 남기고 **부분 산출** 상태로 끝난다. `--force` 없이 **그냥 다시 `run`**하면 실패 교시만 재시도된다(성공한 교시는 SKIP). **실패가 계속되면 파이프라인은 매번 같은 지점에서 멎고 리포트가 나오지 않는다** — 건너뛰기 플래그가 없다. 그 교시를 포기하려면 manifest에서 빼고 다시 실행한다(그 교시는 통째로 미측정 — 리포트 A5·C2에 `manifest 제외 교시 pNN`으로 흔적이 남는다) |

`--force <sNN>`은 **성공한 산출물까지 다시 만들 때**만 쓴다(정의·프롬프트를 바꾼 뒤 재발행). 실패 재시도에는 필요 없다.

## 환경변수

| 변수 | 기본값 | 용도 |
|---|---|---|
| `LA_PARALLEL` | `3` | s30·s40의 교시별 `claude -p` 동시 실행 수(sub-agent 수). `1`이면 순차. 산출물 값은 워커 수와 무관하게 같다 — 사용량 한도(rate limit)에 자주 걸리면 낮춘다. 1 미만·정수 아님은 exit 2 |
| `LA_MODEL` | (로그인 플랜 기본 모델) | LLM 스테이지(s30·s40·s60·s65)의 `claude -p` 모델 교체. **모델을 바꾸면 회차 간 비교 조건이 달라진다.** C3에 기록되는 값은 **s70 실행 시점의 환경변수**다(산출물에 남지 않는다) — 중간에 모델을 바꿔 이어 실행하면 C3가 실제 생성 모델과 어긋난다 |
| `LA_WHISPER_MODEL` | `mlx-community/whisper-large-v3-turbo` | 전사 모델 교체(예: `mlx-community/whisper-tiny` — 빠르지만 오인식 증가). 리포트 C3에 기록된다 |
| `LA_CLAUDE_BIN` | `claude` | `claude` CLI 실행 파일 경로. **테스트 스텁 주입용 seam** |
| `LA_VENV_PY` | `<스킬>/.venv/bin/python` | s10이 쓰는 파이썬. **테스트 seam**(mlx 설치 없이 s10 게이트 확인) |
| `LA_GROWTH_DIR` | (미지정) | 추세 CSV 폴더. **개인용 opt-in — 지정 시에만 추세 CSV 기록·표시**하고, 배포판 기본은 미기록이다(리포트 C3에 `추세 CSV: 미기록(LA_GROWTH_DIR 미지정)`). 회차를 이어 보는 개인 저장소에서는 **한 위치로 고정** — 갈라지면 회차 비교가 조용히 리셋된다 |

## 운영 규칙 (분석 전 확인)

- 수강생 음성 포함 시 **사전 고지·동의**(B2B는 계약 조항, 공개강의는 모집 페이지 고지).
- 녹음 파일 **외부 공유·해외 SaaS 업로드 금지**(음성권·국외이전). 오디오는 로컬에만 있지만 **전사 텍스트는 Anthropic(국외)으로 나간다** — 마스킹은 `mask_names`에 적은 실명만 치환하고 기본값은 비어 있다. **mask_names 게이트(절차 4)에서 반드시 채우게 한다**(비어 있으면 s20이 경고를 찍지만 실행은 계속된다). **`plan`을 달았다면 그 계획 문서의 실명도** 같은 목록에 넣는다 — 계획 본문도 s40이 마스킹 후 전송한다.
- 녹취록 내보내기 전 강의 전후 잡담(정산 논의 등) **트리밍**.
- 분석 결과를 **수강생 평가·수료 판정에 사용 금지**(AI기본법 고영향 재검토 트리거).

## 금지 (프롬프트·리포트 공통 불변)

점수·등급 산출 / 감정·표정 해석 / 수강생 개인 평가 / 근거 없는 총평·조언 / 전달 지표의 학습 성과 해석.
